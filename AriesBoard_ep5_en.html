PCI Card Project Episode 5: PCI Driver for Windows

In this episode, we will write a driver for our PCI card on Windows. We will use WinDriver (http://www.jungo.com), which is a tool that makes driver development much easier.

WinDriver simplifies accessing the memory map of the card.

Once the driver is installed, we can verify the device in the Windows Device Manager.
