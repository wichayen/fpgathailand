1.1.  DPU ของ Xilinx (ฮาร์ดแวร์)

 

1.1.1. การเตรียม DPU IP ของ Xilinx

DPU IP เวอร์ชันล่าสุดในปัจจุบันไม่รองรับชิปตระกูล Zynq-7000 แล้ว (เวอร์ชันสุดท้ายที่รองรับคือ v3.3) ในบทความนี้เราจึงเลือกใช้เวอร์ชัน 3.0 เพื่อนำมาติดตั้งลงบน Zynq-7000 โดยตัว DPU IP ที่รองรับ Zynq-7000 นั้นมักจะไม่ค่อยมีให้ดาวน์โหลดทั่วไป แต่สามารถดึงออกมาได้จากแพ็กเกจ zcu102-dpu-trd-2019-1-190809.zip

หลังจากแตกไฟล์ zcu102-dpu-trd-2019-1-190809.zip แล้ว จะพบโฟลเดอร์ชื่อ dpu_ip อยู่ที่ไดเรกทอรี zcu102-dpu-trd-2019-1-timer\pl\srcs ให้คัดลอกโฟลเดอร์ dpu_ip ทั้งหมดไปไว้ในโฟลเดอร์ที่ต้องการ (ในตัวอย่างนี้จะวางไว้ที่ D:\xilinx\pynq_z2\AI\DPU\ip_repo)

(และไฟล์โปรเจกต์ Vivado จะอยู่ที่ D:\xilinx\pynq_z2\AI\DPU\Pynq-Z2_2020_1\pynqz2_dpu.xpr)

ในหน้าต่าง IP Catalog ให้คลิกที่ Add Repository แล้วเลือกเพิ่มโฟลเดอร์ dpu_ip เข้ามาในโปรเจกต์

 

 

1.1.3. การติดตั้ง DPU IP


‐ เปิดหน้าต่าง Block Design จากนั้นเพิ่มบล็อก DPU IP เข้ามา แล้วทำการเชื่อมต่อเข้ากับ Processing System (Zynq) ดังรูปด้านล่าง

 

พอร์ตอินเทอร์เฟซหลักของ DPU ประกอบด้วย:

1. S_AXI, s_axi_aclk

ใช้สำหรับการกำหนดค่าและควบคุมการทำงานของ DPU โดยเชื่อมต่อเข้ากับ AXI Master (M_AXI_GP) ของ Zynq

2. M_AXI_DATA0, M_AXI_DATA1, M_AXI_INSTR, m_axi_dpu_aclk

ใช้สำหรับรับส่งข้อมูลและคำสั่งระหว่างหน่วยความจำกับ DPU โดยเชื่อมต่อเข้ากับพอร์ต AXI Slave (S_AXI_HP0 - S_AXI_HP2) ของ Zynq

3. dpu_2x_clk

รับสัญญาณ Clock ที่มีความถี่เป็น 2 เท่าของ m_axi_dpu_aclk เพื่อใช้ในการประมวลผลภายใน DPU Core

4. dpu_interrupt

สัญญาณ Interrupt แจ้งเตือนสถานะการทำงานของ DPU ส่งกลับไปยัง Zynq

※ สัญญาณ Clock ที่ป้อนเข้าสู่ DPU IP มีทั้งหมด 3 สัญญาณ ดังนี้:

• s_axi_aclk: สัญญาณ Clock สำหรับบัสควบคุม (Zynq -> DPU) กำหนดความถี่เป็น 100 MHz

• m_axi_dpu_aclk: สัญญาณ Clock สำหรับการเข้าถึงหน่วยความจำ (DPU -> Zynq) กำหนดความถี่เป็น 150 MHz

• dpu_2x_clk: สัญญาณ Clock ความถี่สองเท่าสำหรับแกน DPU Core กำหนดความถี่เป็น 300 MHz

โดยสัญญาณ Clock 150 MHz และ 300 MHz จะถูกสร้างขึ้นจากโมดูล Clocking Wizard (PLL) แล้วป้อนเข้าสู่พอร์ต m_axi_dpu_aclk และ dpu_2x_clk ตามลำดับ

 

‐ เนื่องจากบอร์ด PYNQ-Z2 มีทรัพยากรลอจิก (Logic Cells) บน FPGA จำกัด เพื่อลดการใช้ทรัพยากรฮาร์ดแวร์ของ DPU ให้ปรับคอนฟิก Arch of DPU เป็น B1152


1.1.4. การ Export ข้อมูลฮาร์ดแวร์ (.XSA)


หลังจากทำ Synthesis, Implementation และ Generate Bitstream ใน Vivado เสร็จสมบูรณ์แล้ว ให้ Export ข้อมูลฮาร์ดแวร์ (.xsa) ออกไปใช้งาน โดยไปที่เมนู File -> Export -> Export Hardware (อย่าลืมติ๊กเลือก Include bitstream)

  --method 1 \

  --input_fn graph_input_fn.calib_input \

1.2.4. การทดสอบบนบอร์ดฮาร์ดแวร์จริง (Deployment on PYNQ-Z2)


การทดสอบบนบอร์ดจริงจำเป็นต้องเขียนโปรแกรมควบคุม DPU ขึ้นมา โดยในการทดลองนี้เราจะใช้โปรแกรมตัวอย่างที่เตรียมไว้ในเอกสารอ้างอิง

 ‐ ขั้นตอนการเตรียม MicroSD Card:

สร้างพาร์ติชันบน MicroSD Card ด้วยโปรแกรม GParted ดังนี้:

Partition 1: FAT32 (สำหรับไฟล์ Boot)

Partition 2: EXT4 (สำหรับ Root Filesystem)

คัดลอกไฟล์ U-Boot, Kernel Image และ Root Filesystem ลงใน SD Card:

$ sudo mkdir /mnt/sdb1

$ sudo mkdir /mnt/sdb2

 

$ sudo mount /dev/sdb1 /mnt/sdb1

$ cd ~/pynqz2_dpu/images/linux/

$ sudo cp BOOT.BIN image.ub /mnt/sdb1/.

$ sudo umount /mnt/sdb1

 

$ sudo mount /dev/sdb2 /mnt/sdb2

$ sudo tar xzf rootfs.tar.gz -C /mnt/sdb2/

$ sync

$ cd ~/Desktop/YOLO-on-PYNQ-Z2/DPU\ implementation/Petalinux/

$ sudo cp -vr ./zynq7020_dnndk_v3.1/* /mnt/sdb2/home/root/

$ sudo cp -vr ./zynq7020_dnndk_v3.1 /mnt/sdb2/home/root/

$ sync

$ sudo umount /mnt/sdb2

 

‐ ในโฟลเดอร์โปรเจกต์ Deployment จะมีไฟล์ซอร์สโค้ด .cpp และ Makefile เตรียมไว้แล้ว ให้เรานำไฟล์โมเดล YOLO (dpu_yolo.elf) ที่เพิ่งคอมไพล์ได้ไปวางแทนที่:

$ cd ~/Desktop/YOLO-on-PYNQ-Z2/DNNDK/compilation/compile

$ cp dpu_yolo.elf ~/Desktop/YOLO-on-PYNQ-Z2/Deployment/yolo_pynqz2/model/.

$ cp yolo_kernel_graph.jpg ~/Desktop/YOLO-on-PYNQ-Z2/Deployment/yolo_pynqz2/info/.

$ cp yolo_kernel.info ~/Desktop/YOLO-on-PYNQ-Z2/Deployment/yolo_pynqz2/info/.

 

‐ นำ MicroSD Card เสียบเข้ากับบอร์ด PYNQ-Z2 แล้วเปิดสวิตช์เปิดเครื่อง รอจนกระทั่งระบบปฏิบัติการ Linux บูตเสร็จสมบูรณ์ จากนั้นทดสอบตรวจสอบการเข้าถึงรีจิสเตอร์ของ DPU ด้วยคำสั่ง devmem (รันบนบอร์ด PYNQ-Z2):

 

‐ เชื่อมต่อเทอร์มินัลหรือล็อกอินผ่าน SSH (เช่น ใช้โปรแกรม MobaXterm) โดยมี Username: "root" และ Password: "root"

 

‐ ติดตั้งรันไทม์ DNNDK บนบอร์ด PYNQ-Z2:

root@pynqz2_dpu:~# cd zynq7020_dnndk_v3.1/

root@pynqz2_dpu:~/zynq7020_dnndk_v3.1# sh install.sh

 

‐ คัดลอกโฟลเดอร์โปรแกรมแอปพลิเคชัน (yolo_pynqz2) ไปยังบอร์ด PYNQ-Z2 (สามารถลากและวางไฟล์ผ่านหน้าต่าง SFTP ใน MobaXterm ได้):

 

 

‐ คอมไพล์และรันแอปพลิเคชันตรวจจับวัตถุ (รันบนบอร์ด PYNQ-Z2):

root@pynqz2_dpu:~/yolo_pynqz2# make

root@pynqz2_dpu:~/yolo_pynqz2# ./yolo_image dog.jpg

เมื่อโปรแกรมประมวลผลเสร็จสมบูรณ์ จะแสดงผลลัพธ์การตรวจจับวัตถุบนภาพตัวอย่าง (dog.jpg) ดังรูปด้านล่าง
