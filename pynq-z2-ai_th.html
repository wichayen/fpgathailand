AI (Object Detection ด้วย Xilinx DPU IP)

DPU (Deep Learning Processing Unit) ของ Xilinx เป็น IP สำหรับเร่งความเร็วการประมวลผลโครงข่ายประสาทเทียมแบบ CNN บน FPGA/SoC ผู้ใช้ไม่ต้องออกแบบ accelerator เอง เพียงนำโมเดลที่เทรนแล้วไป quantize และคอมไพล์ด้วยเครื่องมือของ Xilinx ก็สามารถรัน inference บนบอร์ดได้ บทความนี้จะพาไปทำตัวอย่างครบวงจรของการ ตรวจจับวัตถุด้วย YOLOv3 บน DPU ของบอร์ด Pynq-Z2 (Zynq-7000) ตั้งแต่สร้างฮาร์ดแวร์ใน Vivado, build Linux ด้วย Petalinux, แปลงและคอมไพล์โมเดล ไปจนถึงรันบนบอร์ดจริง

1 DPU ของ Xilinx

1.1 การหา DPU IP ของ Xilinx

DPU IP รุ่นล่าสุดไม่รองรับ Zynq-7000 แล้ว แต่เวอร์ชันถึง 3.3 ยังรองรับ ครั้งนี้จะ implement บน Zynq-7000 จึงใช้เวอร์ชัน 3.0 DPU IP ที่รองรับ Zynq-7000 ซึ่งหา download แทบจะไม่ได้แล้ว (แต่มี DPU IP อยู่ใน zcu102-dpu-trd-2019-1-190809.zip ลิงก์ดาวน์โหลดอยู่ท้ายบทความ)

แตกไฟล์ zcu102-dpu-trd-2019-1-190809.zip จะมีโฟลเดอร์ชื่อ dpu_ip ใน zcu102-dpu-trd-2019-1-timer\pl\srcs ให้คัดลอกโฟลเดอร์ dpu_ip ทั้งโฟลเดอร์ไปไว้ที่ใดที่หนึ่ง ครั้งนี้วางไว้ที่ D:\xilinx\pynq_z2\AI\DPU\ip_repo

(โปรเจกต์ Vivado คือ D:\xilinx\pynq_z2\AI\DPU\Pynq-Z2_2020_1\pynqz2_dpu.xpr)

1.2 เพิ่ม DPU IP ลงใน IP Catalog

คลิก Add Repository ใน IP Catalog แล้วเพิ่ม dpu_ip

1.3 การ implement DPU IP

เปิด Block design แล้วใส่ DPU IP จากนั้นเชื่อมต่อกับ Zynq ดังภาพ

อินเทอร์เฟซของ DPU มีหลายพอร์ต:

พอร์ต หน้าที่ เชื่อมต่อกับ
S_AXI, s_axi_aclk ตั้งค่าการทำงานของ DPU (register) AXI master ของ Zynq (M_AXI_GP)
M_AXI_DATA0, M_AXI_DATA1, M_AXI_INSTR, m_axi_dpu_aclk DPU อ่าน/เขียนข้อมูลและคำสั่งกับหน่วยความจำ รวมถึงส่งออกผลการคำนวณ AXI slave ของ Zynq (S_AXI_HP0~2)
dpu_2x_clk ป้อนคล็อกที่เร็วเป็น 2 เท่าของ m_axi_dpu_aclk เอาต์พุตของ PLL
dpu_interrupt เอาต์พุตอินเทอร์รัปต์ของ DPU IRQ_F2P ของ Zynq

Clock ที่ป้อนให้ DPU IP มี 3 ตัว:

คล็อก ใช้งาน ความถี่
s_axi_aclk สื่อสาร Zynq → DPU 100 MHz
m_axi_dpu_aclk คำนวณของ DPU และสื่อสาร DPU → Zynq 150 MHz
dpu_2x_clk คำนวณของ DPU 300 MHz

150 MHz และ 300 MHz สร้างด้วย PLL แล้วป้อนให้ m_axi_dpu_aclk และ dpu_2x_clk

Note: dpu_2x_clk ต้องเป็น 2 เท่าของ m_axi_dpu_aclk เสมอ และควรมาจาก PLL ตัวเดียวกันเพื่อให้เฟสสัมพันธ์กัน

FPGA บนบอร์ด Pynq-Z2 มีจำนวนลอจิกน้อย เพื่อลดจำนวนการใช้ลอจิกของ DPU จึงเปลี่ยน Arch of DPU เป็น B1152

1.4 สร้างข้อมูลฮาร์ดแวร์ (.XSA)

เมื่อคอมไพล์โปรเจกต์ใน Vivado เสร็จ ให้ export ข้อมูลฮาร์ดแวร์ (.xsa) โดยคลิก File → Export → Export Hardware (เลือก Include bitstream)

2.3.1 เพิ่มการตั้งค่าที่จำเป็นเกี่ยวกับ DPU

เพิ่มโมดูล dpu ใน rootfs config:

gedit project-spec/meta-user/conf/user-rootfsconfig
CONFIG_dpu
gedit project-spec/meta-user/conf/petalinuxbsp.conf
IMAGE_INSTALL_append = "dpu"

แก้ Device Tree:

gedit project-spec/meta-user/recipes-bsp/device-tree/files/system-user.dtsi
/include/ "system-conf.dtsi"

&amba {
    xlnk {
        compatible = "xlnx,xlnk-1.0";
    };
};

&amba {
    dpu {
        #address-cells = <1>;
        #size-cells = <1>;
        compatible = "xilinx,dpu";
        base-addr = <0x4f000000>;   //CHANGE THIS ACCORDING TO YOUR DESIGN
        dpucore {
            compatible = "xilinx,dpucore";
            interrupt-parent = <&intc>;
            interrupts = <0 29 4>;  //CHANGE THIS ACCORDING TO YOUR DESIGN
            core-num = <0x1>;       //CHANGE THIS ACCORDING TO YOUR DESIGN
        };
    };
};

//usb device tree
/ {
    usb_phy0: usb_phy@0 {
        compatible = "ulpi-phy";
        #phy-cells = <0>;
        reg = <0xe0002000 0x1000>;
        view-port = <0x0170>;
        drv-vbus;
    };
};

&usb0 {
    dr_mode = "host";
    usb-phy = <&usb_phy0>;
};
Note: ค่า 3 จุดที่มีคอมเมนต์ "CHANGE THIS" ต้องให้ตรงกับการออกแบบฮาร์ดแวร์ของเรา
ค่า ต้องตรงกับ
base-addr ที่อยู่ของ DPU ใน Address Editor ของ Vivado
interrupts = <0 29 4> ช่อง IRQ_F2P ที่ต่อ dpu_interrupt ไว้ (ครั้งนี้คือหมายเลข 61 → 61 − 32 = 29)
core-num จำนวนคอร์ DPU ในดีไซน์ (ครั้งนี้ 1 คอร์)

4 ทดสอบบนบอร์ดจริง

การทดสอบบนบอร์ดจริงต้องมีโปรแกรมฝั่งแอป แต่ครั้งนี้ใช้ตัวที่เตรียมไว้ในเอกสารอ้างอิง

4.1 สร้าง SD card

สร้างพาร์ทิชันด้วย gparted ดังนี้:

พาร์ทิชัน ฟอร์แมต ใช้เก็บ
Partition 1 FAT32 BOOT.BIN, image.ub
Partition 2 ext4 Root filesystem (rootfs)

คัดลอก U-Boot, Linux ฯลฯ ลงใน SD card (ในที่นี้ SD card คือ /dev/sdb ให้ตรวจสอบชื่อ device ของเครื่องตัวเองก่อนเสมอ):

sudo mkdir /mnt/sdb1
sudo mkdir /mnt/sdb2
sudo mount /dev/sdb1 /mnt/sdb1
cd ~/pynqz2_dpu/images/linux/
sudo cp BOOT.BIN image.ub /mnt/sdb1/.
sudo umount /mnt/sdb1
sudo mount /dev/sdb2 /mnt/sdb2
sudo tar xzf rootfs.tar.gz -C /mnt/sdb2/
sync

คัดลอก DNNDK ฝั่งบอร์ดไปไว้ใน home ของ root:

cd ~/Desktop/YOLO-on-PYNQ-Z2/DPU\ implementation/Petalinux/
sudo cp -vr ./zynq7020_dnndk_v3.1 /mnt/sdb2/home/root/
sync
sudo umount /mnt/sdb2
