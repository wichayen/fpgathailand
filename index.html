คำถามที่พบบ่อยเกี่ยวกับ FPGA Thailand

ข้อมูลเบื้องต้นเกี่ยวกับ FPGATHAILAND แหล่งเรียนรู้และการพัฒนางานออกแบบ FPGA ในประเทศไทย

FPGATHAILAND (FPGA Thailand) คือแพลตฟอร์มและคลังความรู้เชิงปฏิบัติการด้านการออกแบบวงจรดิจิทัลด้วย FPGA (Field Programmable Gate Array), ระบบสมองกลฝังตัว (Embedded Systems), และการพัฒนา Hardware Acceleration ในประเทศไทย จัดทำโดยคุณ Wichayen เพื่อแบ่งปันความรู้ทั้งระดับเริ่มต้นไปจนถึงระดับ Industrial & Validation

เนื้อหาครอบคลุมหลากหลายด้าน ได้แก่:
  • คอร์สเรียน FPGA พื้นฐาน: เริ่มต้นตั้งแต่ Digital Logic, ภาษา VHDL, เครื่องมือออกแบบ, ไปจนถึงการ Simulation ด้วย Modelsim
  • บอร์ด PYNQ-Z2 & Xilinx Zynq: การใช้ Vivado, High-Level Synthesis (Vitis HLS), AI บน FPGA ด้วย DPU IP และ GUI บนจอแสดงผลด้วย LVGL
  • High-Speed Bus & Custom Hardware: โครงงานการออกแบบบอร์ด PCI/PCIe พร้อมการเขียน Linux & Windows Device Driver, การเชื่อมต่อ USB 2.0 FIFO (EZ-USB FX2)
  • Hardware Verification: การใช้ UVVM และการวิเคราะห์ Code Coverage

เหมาะสำหรับนักศึกษาคณะวิศวกรรมศาสตร์ (คอมพิวเตอร์ / อิเล็กทรอนิกส์ / ไฟฟ้า), วิศวกรฮาร์ดแวร์, นักวิจัย, และผู้พัฒนาในประเทศไทยที่ต้องการต่อยอดทักษะด้าน Digital Design, SoC, Acceleration และ Linux Kernel Driver จากฮาร์ดแวร์จริง
