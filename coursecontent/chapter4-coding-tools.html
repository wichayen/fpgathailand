chapter4-coding-tools

ในบทนี้จะพาไปดู IDE, Text Editor และเครื่องมือช่วยเขียนโค้ด (Coding Tools & Assistants) ที่ผู้เขียนใช้งานจริงในการพัฒนา FPGA/VHDL ตั้งแต่เครื่องมือพื้นฐานไปจนถึง AI Coding Agent

1 Traditional & Lightweight Text Editors

1.1 Notepad++

Text Editor น้ำหนักเบา ยอดนิยมสำหรับการเปิดดูและแก้ไขไฟล์อย่างรวดเร็ว

  • จุดเด่น:
    • โหลดเร็ว ไม่กินทรัพยากรเครื่อง
    • มี Built-in Syntax Highlighting สำหรับ VHDL และ Verilog
    • รองรับ Plugin ต่างๆ เช่น Compare Plugin สำหรับเปรียบเทียบไฟล์ VHDL สองเวอร์ชัน
  • ข้อจำกัด: ไม่มีระบบ Code Intelligence (เช่น Auto-complete ลึกๆ หรือ Linting แบบ Real-time)

2 Modern Code Editors (VS Code & Extensions)

Visual Studio Code (VS Code) เป็น Code Editor มาตรฐานยุคใหม่ที่นิยมใช้กันอย่างแพร่หลาย มี Ecosystem ของ Extension ที่ครอบคลุมการพัฒนา FPGA โดยส่วนตัวมี Extension หลักๆ ที่ติดไว้ใช้งานประจำดังนี้

2.1 Better TODO Tree / Todo Tree

Extension สำหรับปักหมุด Comment ชั่วคราวในโค้ด เช่น -- TODO: Add reset logic หรือ -- FIXME: Check setup time แล้ว Extension จะรวบรวมทุกจุดที่ Comment ไว้มาแสดงเป็นรายการเดียวใน Sidebar ให้ไล่เช็คได้ครบในที่เดียว ไม่ต้องมานั่งไล่หาทีละไฟล์ ช่วยให้ไม่พลาดจุดที่ยังเขียนไม่เสร็จก่อนนำโค้ดไป Synthesis

2.2 Sigasi Visual HDL (SVH) & Linting Tools

Sigasi เป็นเครื่องมือระดับมืออาชีพสำหรับการวิเคราะห์และตรวจสอบคุณภาพโค้ด HDL (VHDL/SystemVerilog) ดูตัวอย่างการใช้งานคร่าวๆ ได้ที่ Sigasi: VS Code Extension สุดเทพสำหรับคนเขียน VHDL/Verilog

2.2.1 Real-time Syntax & Semantic Checking (Linting)

  • ตรวจจับข้อผิดพลาดทันทีขณะพิมพ์ (เช่น การลืมใส่ Signal ใน Sensitivity List, การเกิด Unintended Latch, หรือ Type Mismatch)
  • ช่วยลดเวลาจากการต้องรอคอมไพล์ใน Tool ใหญ่ๆ อย่าง Vivado หรือ Quartus
  • อ่านรายละเอียดเพิ่มเติม: Sigasi VHDL Linting

2.2.2 Naming Conventions Enforcement

  • กำหนดและบังคับใช้มาตรฐานการตั้งชื่อ (Naming Rules) เพื่อให้ทีมพัฒนาอ่านโค้ดเข้าใจตรงกัน เช่น:
    • สัญญาณ Input: i_clock, i_reset_n
    • สัญญาณ Output: o_data_valid
    • สัญญาณ Internal: s_cnt_reg, r_state
    • Constants: C_DATA_WIDTH
  • อ่านรายละเอียดเพิ่มเติม: Sigasi Naming Conventions
note:

เวอร์ชันที่ใช้งานได้ฟรีคือ Community Edition เท่านั้น ถ้าจะนำไปใช้งานในบริษัท/งานเชิงพาณิชย์ ต้องเช็ค License ให้ดีก่อนว่าเข้าเงื่อนไข Free หรือไม่

2.3 TerosHDL (ทางเลือกฟรี 100%)

TerosHDL เป็น VS Code Extension แบบ Open-source เฉพาะทาง HDL โดยตรง (VHDL/Verilog/SystemVerilog) รวมเครื่องมือที่จำเป็นไว้ในตัวเดียว:

  • State Machine Viewer: วาด State Diagram จากโค้ด VHDL ให้อัตโนมัติ ช่วยตรวจสอบ Logic ของ FSM ได้ง่ายขึ้น
  • Hierarchy / Dependency Viewer: แสดงโครงสร้าง Entity/Module และความสัมพันธ์ระหว่างไฟล์ในโปรเจกต์
  • Template Generator: สร้างโครง Entity, Process, Testbench ให้อัตโนมัติ
  • Simulator Integration: เชื่อมต่อกับ Simulator ได้หลายตัว เช่น GHDL, ModelSim, Vivado, Quartus

จุดต่างหลักจาก Sigasi คือ TerosHDL ฟรีแบบไม่มีเงื่อนไข ไม่ว่าจะใช้ส่วนตัวหรือในบริษัทก็ไม่ต้องกังวลเรื่อง License แต่ความสามารถด้าน Real-time Linting/Semantic Checking จะไม่ลึกเท่า Sigasi ซึ่งเป็นเครื่องมือระดับ Commercial

3 AI Coding Assistants & Agents in FPGA Development

3.1 AI Agent Tools ที่มี Free Tier ให้ทดลองใช้

  • Antigravity

    • Agentic IDE จาก Google (ต่อยอดจาก Gemini) มี Editor ในตัวพร้อม AI Agent ที่แก้ไขไฟล์, รันคำสั่ง Terminal และวางแผนงานหลายขั้นตอนได้เอง เหมาะกับงานที่ต้องแก้ไฟล์หลายไฟล์พร้อมกัน เช่น ปรับ VHDL หลาย Module ให้ตรงตาม Naming Convention เดียวกัน
    • ⚠️ ปัจจุบันฟรีเฉพาะช่วง Public Preview เท่านั้น และ Quota ของ Free Tier ถูกปรับลดมาแล้วหลายรอบตั้งแต่เปิดตัว ยังไม่มีการยืนยันราคาถาวรในระยะยาว

  • Codex

    • AI Coding Agent จาก OpenAI ใช้งานผ่าน CLI หรือ IDE Extension ได้ รับคำสั่งเป็นภาษาธรรมชาติแล้วลงมือแก้โค้ด/รันเทสต์ให้อัตโนมัติ เหมาะกับงาน Refactor หรือสร้าง Boilerplate Code (เช่น Testbench เปล่าจาก Entity)
    • ⚠️ Free Tier มาจาก ChatGPT Free Plan ซึ่งมี Quota ค่อนข้างจำกัด เหมาะสำหรับลองใช้งานสั้นๆ มากกว่าใช้ทำงานประจำวัน ถ้าต้องการใช้จริงจังต้องอัปเกรดเป็นแพลนที่มีค่าใช้จ่าย

  • Opencode

    • เครื่องมือ Agentic Coding แบบ Open-source รันผ่าน Terminal จุดเด่นคือสลับ Model Provider ได้อิสระ (เชื่อมต่อได้ทั้ง Cloud API เช่น Gemini/Claude หรือ Local LLM ที่รันบนเครื่องตัวเอง) เหมาะสำหรับผู้ที่ต้องการควบคุมค่าใช้จ่ายและความเป็นส่วนตัวของโค้ด
    • ตัวโปรแกรมเองฟรีแบบไม่มีเงื่อนไข (Open-source, ไม่บังคับ Subscription) ต่างจาก Antigravity และ Codex ตรงที่ค่าใช้จ่ายจะไปอยู่ที่ Provider ที่เลือกใช้แทน (ถ้าใช้ Cloud API) หรือไม่มีค่าใช้จ่ายเลยถ้าใช้ Local LLM

  • GitHub Copilot

    • AI Coding Assistant จาก GitHub ใช้งานเป็น Extension ใน VS Code (และ IDE อื่นๆ) ได้โดยตรง จุดเด่นคือ Auto-complete แบบ Inline ขณะพิมพ์โค้ด บวกกับโหมด Chat/Agent ให้สั่งงานเป็นภาษาธรรมชาติ และรองรับ MCP Server ได้เช่นกัน ผูกกับ Ecosystem ของ GitHub แน่นหนา (PR, Code Review) เหมาะกับคนที่ใช้ GitHub เป็นหลักอยู่แล้ว
    • Free Tier เป็นแบบถาวร ไม่ใช่แค่ Preview ให้ Auto-complete 2,000 ครั้ง/เดือน และ Chat/Agent ประมาณ 50 ครั้ง/เดือน เพียงพอสำหรับลองใช้งานเบื้องต้น ถ้าต้องการ Auto-complete/Agent แบบไม่จำกัด ต้องอัปเกรดเป็น Pro ($10/เดือน)
note:

การใช้งาน AI tools เหล่านี้ต้องระวังเรื่องการส่งข้อมูลออกไปข้างนอก เพราะบางบริษัทเค้ามี ข้อกำหนด ห้ามเปิดเผยข้อมูล (Source Code, Register Map, IP ภายใน) ออกสู่ Cloud AI
