1 Pynq-Z2 FM Radio: ทำ FM demodulate ด้วย FPGA + RTL-SDR

เผยแพร่เมื่อ: 8 ตุลาคม 2026 โดย Wichayen

พอดีไปเจอโปรเจคน่าสนใจตัวนี้ครับ PYNQ_Z2_FM_Radio เลยลองทำตามดู โปรเจคนี้เอา FPGA มาทำ FM demodulate โดยรับสัญญาณจาก RTL-SDR (dongle USB ราคาไม่กี่ร้อยบาท) แล้วให้ FPGA ทำงาน DSP ทั้งหมด จนได้เสียงวิทยุ FM ออกมา จะเรียกว่าเป็นการใช้ FPGA ทำ SDR (Software Defined Radio) ก็น่าจะได้ครับ คิดว่าเหมาะเป็นตัวอย่างของการใช้ hardware acceleration สำหรับการทำ SDR

การทดลองนี้ใช้อุปกรณ์และเครื่องมือดังนี้

  • Hardware : PYNQ-Z2, RTL-SDR USB dongle
  • Tool : Vitis HLS + Vivado 2022.1
  • PYNQ image : version 2.7

ตัว RTL-SDR USB dongle นี้ซื้อได้ตาม Shopee เลยครับ เป็นตัวที่เค้าเอามารับสัญญาณ TV กัน

2 concept การทำงาน

ระบบแบ่งงานระหว่าง CPU (Python บน PYNQ) กับ FPGA ดังนี้

ขั้น ทำอะไร ทำที่ไหน
1 RTL-SDR รับคลื่น FM แล้วแปลงเป็น IQ samples CPU ดึงค่าผ่าน USB CPU (jupyter notebook)
2 CPU (Python) อ่านข้อมูลจาก USB แล้วเขียนลง DDR CPU (jupyter notebook)
3 FPGA อ่านข้อมูลจาก DDR ผ่าน AXI DMA (MM2S) เข้า fir_decimation FPGA
4 คำนวณต่อเนื่อง: FIR decimation → Quadrature demodulate → Low pass filter 1 → Low pass filter 2 FPGA
5 ผลลัพธ์ (เสียงที่ demodulate แล้ว) ถูกส่งกลับลง DDR ผ่าน AXI DMA (S2MM) FPGA
6 CPU อ่านข้อมูลเสียงจาก DDR จะได้ข้อมูลเสียงออกมา CPU (jupyter notebook)
Note : Decimation คืออะไร?

Decimation คือการลดจำนวน sample โดยเก็บไว้แค่ทุก ๆ N ตัว แล้วทิ้งที่เหลือ (÷N) เช่น ÷5 คือเก็บ 1 ตัว ทิ้ง 4 ตัว ทำให้ sample rate ลดลง 5 เท่า ในโปรเจคนี้ใช้ลดข้อมูลจาก 1.92 MS/s เหลือ 48 kHz

2.1 Sample rate ในแต่ละ stage

RTL-SDR ส่ง IQ มาที่ 1.92 MS/s แล้วลด rate ลงเรื่อย ๆ จนเหลือ 48 kHz ซึ่งเป็น audio rate ปกติ (รวม decimation 40x)

Stage Decimation Sample rate ออก Interface ทำหน้าที่
RTL-SDR (input) - 1.92 MS/s 8-bit IQ รับคลื่น RF แล้วแปลงเป็น IQ 8-bit ให้ CPU ดึงไปทาง USB
FIR Decimation Filter ÷5 384 kHz AXI4-Stream 8-bit → 32-bit low-pass กรองสัญญาณนอกย่านที่ต้องการทิ้ง แล้วลด rate ÷5
Quadrature Demod ÷1 384 kHz 2× AXI4-Stream (I, Q) → 1 stream ทำ FM demodulation (ถอดสัญญาณเสียงออกจาก IQ)
Low Pass Filter 1st ÷4 96 kHz AXI4-Stream 32-bit fixed-point low-pass ตัดสัญญาณที่ไม่ใช่ย่านเสียง แล้วลด rate ÷4
Low Pass Filter 2nd ÷2 48 kHz AXI4-Stream 32-bit → 16-bit low-pass ขั้นสุดท้าย ลด rate ÷2 เหลือ 48 kHz และแปลงเป็น 16-bit

2.2 หน้าที่ของ CPU กับ FPGA

ส่วน ทำอะไร
CPU (ARM) อ่าน IQ จาก RTL-SDR ผ่าน USB (pyrtlsdr), เขียนลง DDR, สั่ง DMA, เล่นเสียง
FPGA (AXI DMA) MM2S: DDR → stream เข้า FPGA / S2MM: stream จาก FPGA → DDR
FPGA (HLS) FIR decimation → demod → LPF1 → LPF2
ข้อสังเกตด้านประสิทธิภาพ

จะเห็นว่างาน DSP ที่หนักที่สุด (filter ที่ 1.92 MS/s) ถูกส่งให้ FPGA ทำแบบ real-time ทำให้ CPU ไม่ต้องรับภาระการประมวลผลสัญญาณต่อเนื่องที่ความถี่สูง

3 วิธีการทำ

ขั้นตอนมี 2 ส่วนหลัก คือแปลงโค้ด C++ ให้เป็น IP ด้วย Vitis HLS แล้วเอา IP เหล่านั้นไปต่อกันใน Vivado เพื่อสร้าง bitstream

3.1 HLS compile

เปิด Vitis HLS ในโหมด terminal แล้วรันคำสั่ง vitis_hls เพื่อแปลงโค้ด C++ ให้เป็น IP (คือการแปลง component ต่าง ๆ ที่ต้องใช้ให้กลายเป็น hardware)

ใน repo มี HLS อยู่ 4 ตัว แต่ละตัวอยู่คนละ folder ใต้ hls/ และทำแบบเดียวกันทุกตัว

Folder IP ที่ได้ หน้าที่
fir_decimation_filter FIR Decimation filter + ลด rate ÷5
quadrature_demodulator Quadrature Demodulator FM demod
low_pass_filter_first LPF 1st audio LPF + ลด rate ÷4
low_pass_filter_second LPF 2nd audio LPF + ลด rate ÷2

3.2 สร้าง Vivado project

เริ่มจากเพิ่ม IP ที่ได้จาก HLS เข้าไปใน project

จากนั้นสร้าง block design แล้วต่ออุปกรณ์ทั้งหมดเข้าด้วยกัน โดยหลัก ๆ จะมี

  • ZYNQ7 Processing System
  • AXI DMA (เปิดทั้ง MM2S และ S2MM)
  • HLS IP 4 ตัว ต่อเป็น stream ตาม diagram ในหัวข้อ 2 concept การทำงาน

ต่อสายตามรูปด้านล่าง

หลังจากนั้นสั่ง Synthesis -> Implementation -> Generate Bitstream แล้วเอาไฟล์ .bit และ .hwh ที่ได้ไปใช้บน PYNQ

4 ทดสอบ

4.1 setup

ก่อนใช้ RTL-SDR ตัวนี้ ต้องติดตั้ง library เพิ่มบน PYNQ ก่อน ดังนี้

sudo apt-get update
sudo apt-get install librtlsdr-dev rtl-sdr
echo "blacklist dvb_usb_rtl28xxu" | sudo tee /etc/modprobe.d/blacklist-rtl.conf
sudo pip3 install "pyrtlsdr<3"
sudo reboot
  • บรรทัด blacklist มีไว้กันไม่ให้ kernel driver สำหรับดูทีวี (dvb_usb_rtl28xxu) มาแย่งใช้ dongle
  • ใช้ pyrtlsdr version ต่ำกว่า 3 เพราะตอนนี้ใช้ pynq image 2.7

6 สรุป

โปรเจคนี้แสดงให้เห็นว่า FPGA รับงาน DSP ที่หนักที่สุด (filter ที่ 1.92 MS/s) ได้แบบ real-time ส่วน CPU ทำแค่งาน I/O ผ่าน Python โดยใช้ PYNQ เชื่อมสองส่วนเข้าด้วยกัน แค่ RTL-SDR ราคาไม่กี่ร้อยบาทกับ PYNQ-Z2 ก็ทำ SDR receiver ได้แล้ว
