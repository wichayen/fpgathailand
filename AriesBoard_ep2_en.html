PCI Card Project Episode 2: Aries Board Version A.1

1. The Board

Finally, version A.1 of the Aries board is here. It is designed to be highly versatile, eliminating the need to create a new board every time we want to experiment with something new.

2. Board specification

The specifications of the board are as follows:

Component Specification Note
FPGA Cyclone II 5000 LE (EP2C5Q208C8)
Memory SDRAM: 256Mbit
FPGA config ROM: 4Mbit
Serial Flash memory: 4Mbit
PCI interface 32 bits 66MHz/33MHz Default: 33Mhz
ADC 12 bits / 8 Channels (MCP3208 x 1)
DAC 12 bits / 4 Channels (MCP4922 x 2)
Digital I/O 16 Channels
RS232 1 Channel
LED 8 bit Shared with VGA
VGA 8 bit (RGB:222) Shared with LED
Switch Tact SW x3
Slide SW x 4
Input power 5V

The USB connector on the board works in conjunction with a USB Blaster clone, which is used to program the firmware via JTAG. http://sa89a.net/mp.cgi/ele/ub.htm

Currently, I have successfully configured the FPGA using NIOS II and run a test program to verify the PCI card functionality.
