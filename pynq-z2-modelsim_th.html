การจำลองการทำงานด้วย ModelSim (Simulation with ModelSim)

โดยปกติ Vivado ใช้ xsim เป็นเครื่องมือ simulation เริ่มต้น แต่ก็สามารถใช้ ModelSim ในการ simulate design ของ Vivado ได้เช่นกัน บทความนี้สรุปขั้นตอนตั้งแต่คอมไพล์ไลบรารีของ Xilinx, export script จาก Vivado จนถึงรัน simulation และดู waveform ใน ModelSim

ข้อควรระวัง: ถ้า design ไหนมี IP ที่ต้องใช้ license ของ Xilinx เช่น AXI Verification IP ต้องใช้ไลเซนส์ ดังนั้นถ้าจำลองด้วย ModelSim จะเกิดข้อผิดพลาดเรื่องไลเซนส์ (หากไม่มีไลเซนส์ ModelSim แบบเสียเงิน ก็จำลอง AXI Verification IP ไม่ได้)

ภาพรวมขั้นตอน

ขั้น สิ่งที่ทำ ทำกี่ครั้ง
1 คอมไพล์ Xilinx simulation library ด้วย Vivado ครั้งเดียวต่อ (Vivado version × ModelSim version)
2 Export simulation script จากโปรเจกต์ ทุกครั้งที่ design/ไฟล์ในโปรเจกต์เปลี่ยน
3 แก้ไข script เล็กน้อย ครั้งเดียวต่อการ export
4 รัน compile.do และ simulate.do ใน ModelSim ทุกครั้งที่ simulate

1. คอมไพล์ไลบรารีของ Xilinx ด้วย Vivado

Design ที่ใช้ primitive หรือ IP ของ Xilinx (เช่น unisim, unimacro, secureip, Clocking Wizard, FIFO Generator) ต้องมี library ที่คอมไพล์สำหรับ ModelSim ก่อน

เปิด Vivado แล้วคลิก Tool → Compile Simulation Libraries

ระบุ Compiled library location และ Simulator executable path แล้วคลิก "Compile"

ตัวเลือก ค่าที่ใช้
Simulator ModelSim Simulator
Language / Library All
Family All หรือเฉพาะ family ที่ใช้
Simulator executable path โฟลเดอร์ที่มี vsim.exe, vlog.exe
Compiled library location โฟลเดอร์ปลายทางที่เขียนได้

เมื่อคอมไพล์เสร็จ จะได้ไฟล์ modelsim.ini ออกมาด้วย (เป็นไฟล์ที่ map ชื่อ library ไปยังโฟลเดอร์ที่คอมไพล์ไว้ เมื่อ ModelSim เปิดขึ้น)

หมายเหตุ:
  1. การคอมไพล์ IP ทั้งหมดของ Xilinx ใช้เวลานาน (ประมาณ 1 ชั่วโมง)
  2. จากที่ลองใช้ ModelSim 10.5b (Quartus 17.1) และ Vivado 2020.1 พบว่ามีโมดูลที่คอมไพล์ผิดพลาด 4 โมดูล หากการออกแบบใน Vivado ไม่ได้ใช้โมดูลเหล่านั้นก็น่าจะไม่มีปัญหา

2. Export simulation

เริ่มแรกก่อนจะรันด้วย ModelSim ให้ทดสอบก่อนว่า xsim simulate ได้ไหม (ทดสอบว่า testbench ที่เขียนไว้รันได้จริง) เพื่อแยกปัญหาของ design/testbench ออกจากปัญหาของ ModelSim

ถ้าไม่มีปัญหาก็จะเห็นผลออกมาในหน้า xsim

จากนั้นไปที่ File → Export → Export Simulation

เซ็ตค่าดังนี้

ตัวเลือก ความหมาย
Simulator เลือก ModelSim Simulator
Compiled library location ตำแหน่งที่ได้ compiled library มาแล้วจากหัวข้อ 1. คอมไพล์ไลบรารีของ Xilinx ด้วย Vivado
Export directory ตำแหน่งที่จะให้ Vivado export script สำหรับ ModelSim

เมื่อกด OK จะมีโฟลเดอร์ modelsim ออกมา ข้างในมี script สำหรับรันกับ ModelSim อยู่

3. แก้ไข script

3.1 simulate.do — comment out quit -force ไม่งั้น simulate เสร็จแล้ว ModelSim จะปิดทันที ทำให้ไม่ได้ดู waveform

3.2 compile.do — เพิ่ม vlib modelsim_lib เข้าไปก่อนบรรทัดที่สร้าง library ย่อย (ในเคสที่ทดสอบ script สร้าง library ไม่สำเร็จเพราะยังไม่มีโฟลเดอร์แม่)

ข้อสังเกต: การแก้ไขทั้งสองจุดนี้ต้องทำใหม่ทุกครั้งที่ Export Simulation ซ้ำ (เพราะไฟล์จะถูกเขียนทับ)

4. รัน simulation ใน ModelSim

เปิด ModelSim แล้วเปลี่ยน directory (File → Change Directory) ไปที่โฟลเดอร์ modelsim จากนั้นรันในช่อง Transcript:

do compile.do
do simulate.do

เราก็จะสามารถ simulate ด้วย ModelSim และเปิดดู Waveform ได้แล้ว
